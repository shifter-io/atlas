# API changes by contract date

`/v1/version` and `/v1/codes` serve `contract`, the date of the API's last breaking change
(`build.Contract`). Each section below is one contract date, newest first: one line per field,
`added`, `changed` or `removed`, with its endpoint and, for a change, the old and the new form.
A task that changes a served field adds its lines here, and moves the contract date when the
change is breaking (`AGENTS.md`, "Changing an API field").

## 2026-11-16

- changed (values only, no shape change): the network success score `successScore` (`/v1/home`, `/v1/rankings`, `/v1/targets` and `/v1/overlap` `networks[]`, `/v1/networks` rows, `/v1/networks/{slug}` `network`, `profile`, `ranges.<r>` and `stats.<r>`, the dataset file), its `days[].successScore`, `successScoreDelta`, `profile.performance.successScoreDelta24h`/`30d`, `stats.<r>.alternative.successScore` and `market.mostReliable` (chosen by it) is the network's daily country tests' success by requests (generic_http, the countries that counted, one pooled ratio) scored by its distance from the best network of the kind: `max(1, 10 − (best − yours) in percentage points)`, so the best reads 10; it was the difficulty-weighted mean of every target's rank score (the owner's decision of 2026-11-16, SUCCESS-DAILY-DISTANCE-1, #1229). Its `targets` and `weights` now hold `generic_http` alone (score, weight 1); a network without 100 daily-test requests in the range has a null `score`, `rank` and `rankedOf` with `status` `no_ranked_targets`. 24h at the 2026-11-16 08:06 build: Geonode 10.00, Evomi 9.93, Decodo 9.78, Shifter 8.67, Proxy-Cheap and Rayobyte 1.00. The Index Score, its reliability component, `scores.success` of each target, `challengeScore` and `browserOverall` are unchanged. The first build after the deploy compares the new score with the old one: `successScoreDelta` shows that jump once.
- changed: `/v1/codes` set `score_basis`: `days[].successScore.basis` is `daily_tests` ("The network's daily tests' success by requests, scored by its distance from the best network of its kind."); `all_targets` is removed. Breaking: the contract moves to 2026-11-16 (#1229).
