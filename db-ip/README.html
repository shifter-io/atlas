Local DB-IP database

Place a DB-IP Location + ISP MMDB file in this directory. The supplied local copy is dbip-full-2026-09-14.mmdb. Database files are excluded from Git, wheels and source distributions.

Run atlas db-info to inspect the selected release. atlas dbip update --dest db-ip --base-url URL keeps the newest verified release in dbip-full.mmdb (always that name, replaced atomically), which discovery prefers. Otherwise, if several files exist, set DBIP_MMDB or pass --mmdb explicitly. Enrichment is offline and records the release checksum.
