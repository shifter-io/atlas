Provider credential grammars

Every provider encodes targeting and sessions differently. Each one has a reviewed grammar in src/proxy_index/providers/grammars/<provider>.toml, read by one shared engine, and a public run config in configs/<provider>.toml. Private credentials stay in .secrets/credentials.toml, one table per provider.

Common parameters

Parameters use the same names for every provider and are translated to the provider's own keys: country, region, city, zip, asn, session and ttl. ttl is always in minutes; the grammar converts it to the provider's unit. Provider-only options keep their own names (for example network, filter, mode, strict). Unknown parameters are rejected before any traffic, because most gateways silently ignore misspelled flags and return untargeted IPs.

uv run --no-editable proxy-index run --provider-config configs/oxylabs.toml \
  --credentials-file .secrets/credentials.toml --target generic_http \
  --requests 100 --param country=us --session-policy per_request

Session policies

  • rotate: no session; the gateway assigns a new exit per request (Webshare adds -rotate).
  • gateway: no session; the port or dashboard decides (Geonode sticky ports, Proxy-Seller lists).
  • fixed: the supplied session is reused; inferred when a session is given.
  • per_request, per_worker, per_run: IDs generated from the run ID and scope, in each provider's allowed alphabet and length. Proxy-Seller selects a port slot instead.

Provider rules are enforced: Proxy-Cheap sessions are eight digits and require ttl; SOAX needs at least one targeting flag and lowercase countries; IPRoyal sessions are eight characters; Evomi sessions are 6–10 characters.

Plain HTTP targets

Byteful and Infatica answered every plain-HTTP request with a gateway 301 to HTTPS on 2026-10-22, and FleetProxy, ProxyEmpire and Proxy-Cheap answered 42–46% that way. The redirect carries no CDN headers, so it comes from the proxy path, not the target. Each grammar therefore declares how its network runs the echo test in an optional [testing] table:

  • protocol = "https-only" (Byteful, Infatica): a plain-HTTP echo target such as generic_http runs at the same URL over HTTPS before any request is sent, so the network never receives plain HTTP. Other plain-HTTP targets are refused. The run's target.url shows the HTTPS URL.
  • protocol = "mixed" (FleetProxy, ProxyEmpire, Proxy-Cheap): the request goes out over HTTP; a gateway redirect (301, 302, 303, 307, 308) to the same host over HTTPS is followed once, through the same proxy session and within the same timeout. The HTTPS answer decides the result; latency, body and traffic cover both legs, and the run summary counts followed redirects in redirects. Redirects to another host or to plain HTTP are not followed.
  • Omitted (every other network): default, each target runs over its own scheme and redirects are never followed.

The same table may record max_concurrency = N (an integer, 1–5,000): the highest concurrency the network sustained from one worker in campaign probe. campaign plan runs the network at min(--concurrency, N); without it the requested concurrency is used. Shifter records 2,000.

Non-default networks publish test_protocol in their run config; default run configs are unchanged. List the networks with a given protocol with proxy-index providers --protocol https-only (networks that cannot run a plain-HTTP test) or --protocol mixed; in Python, grammar_ids_by_protocol().

Add a provider

  1. Write src/proxy_index/providers/grammars/<id>.toml: where flags go (username or password), the base template, separators, each flag's format and validation, session generation and gateway endpoints.
  2. Add configs/<id>.toml with credential environment names and defaults.
  3. Add a golden case to tests/test_grammars.py and verify it with a small live run.

Providers whose behavior cannot be expressed as a grammar get a dedicated adapter registered in proxy_index.providers.registry.
